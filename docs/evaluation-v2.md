# Оценка сегментации v2

SSL сейчас обучается; результаты качества SEG ещё не получены. Проверки
метрик и пример отчёта на синтетических данных не являются оценкой модели.

После выбора чекпоинта только по val запустить из корня проекта:

```bash
export PYTHONPATH="$PWD"
python scripts/run_infer.py --config configs/default.yaml \
  --checkpoint checkpoints/v2/seg/best.pt --output results/v2/test
```

Результат: metrics.json и report.html с метриками по всей выборке и отдельно
по openearthmap_sar/fusar_map, матрицами ошибок и четырьмя изображениями
для каждого контрольного тайла: исходник, эталон, предсказание, наложение.
HTML открывается локально вместе с PNG из той же папки. Контрольные индексы
задаются --samples. Legacy-пути без provenance попадают в ungrouped.

Групповые метрики считаются по своим суммарным матрицам ошибок. Общий
показатель считается по суммарной матрице всех пикселей, а не средним между
датасетами. Строки матрицы — эталон, столбцы — предсказание.
Ignore не участвует в метриках. Полностью ignored тайлы считаются отдельно.
mIoU и macro F1 сохраняют прежнее усреднение по всем настроенным классам,
с нулём для отсутствующего класса. Дополнительный mean_iou_present исключает
классы с нулевым union, включая ложноположительные классы в усреднение.
При valid_pixels=0 нули метрик не интерпретировать как качество модели.
Kappa для вырожденного случая с нулевым знаменателем сохраняет прежнюю
конвенцию 0. Перекрывающиеся тайлы учитываются отдельно, как и раньше.

Новые тесты используют известные ответы: смешанные ошибки, ignore,
отсутствующие классы, ложноположительный класс, пустые маски, объединение
групп разных размеров, повторный запуск и генерацию HTML/PNG.

После освобождения GPU и появления SSL-чекпоинта можно выполнить пробу:

```bash
python scripts/probe_seg_batch.py --config configs/default.yaml \
  --pretrained checkpoints/v2/ssl/best.pt --batch-size 8 --steps 5
```

Проба выполняет настоящие SEG forward/backward и AdamW updates на train,
не сохраняет веса и не читает test. Начать с небольшого batch и повышать
постепенно; результат сохраняется в JSON. Это одно GPU: память DDP и его
коммуникации не учитываются. Для финального выбора batch нужен короткий
прогон с двумя GPU и запасом памяти. Во время текущего SSL проба не запускалась.
